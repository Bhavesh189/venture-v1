How v1 scores churn risk (transparent rules)

Reference date = latest last-order date in the uploaded file (demo data uses today).

  • Healthy — ordered within 14 days
  • Watch — no order in 15–29 days
  • Medium — no order in 30–45 days
  • High — no order in 45+ days
  • New-subscriber bump — tenure under 60 days with a 15+ day gap moves one tier up
  • Paused / Churned — shown separately, never counted as "at risk"

These are v1 rules. Later phases replace them with learned models — but the dashboard will always show why a customer was flagged.
